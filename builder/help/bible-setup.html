Set up Bible audio for Cardputer ADV

The firmware includes the Bible reader program, but Bible audio is separate and must be copied to the microSD card. The reader looks under /bible, discovers translation folders there, then searches numbered book folders for MP3 chapters.

Download audio

Faith Comes By Hearing offers MP3 Bible downloads at faithcomesbyhearing.com/audio-bible-resources/mp3-downloads. The page describes the audio as free and asks for your name and email address before download. Follow the site's terms for the translation you choose.

The example used here is the New Living Translation (NLT), English dramatic audio. The Old Testament download in this example contains many MP3 files loose in a folder, named like A01___01_Genesis_______ENGNLTO2DA.mp3. The Cardputer needs those files sorted by book and renamed with a chapter number.

Sort the Old Testament files

Copy the downloaded files to a folder on your computer. The PowerShell script is sort_nlt_bible.ps1; the Linux/macOS shell script is sort_nlt_bible.sh. Both copy the files into the correct book folders and rename them to the pattern the firmware reads.

The PowerShell script defaults to the example download and output locations used during development. Review the paths before running it. Preview first, then add -Apply to copy files:

powershell -ExecutionPolicy Bypass -File .\sort_nlt_bible.ps1
powershell -ExecutionPolicy Bypass -File .\sort_nlt_bible.ps1 -Apply

The shell script previews by default. Pass the input and output folders, then add --apply to write:

bash sort_nlt_bible.sh "/path/to/English_eng_NLT_OT_Drama" "/path/to/NLT Bible"
bash sort_nlt_bible.sh "/path/to/English_eng_NLT_OT_Drama" "/path/to/NLT Bible" --apply

Copy to the microSD card

Copy the finished NLT Bible folder to /bible/NLT Bible on the microSD card. A valid example is:

/bible/NLT Bible/01 - Genesis/Faith Comes By Hearing - Genesis 1.mp3
/bible/NLT Bible/01 - Genesis/Faith Comes By Hearing - Genesis 2.mp3
/bible/NLT Bible/02 - Exodus/Faith Comes By Hearing - Exodus 1.mp3

Book folder numbers follow the standard Bible order: 01 - Genesis through 39 - Malachi. Keep every chapter MP3 inside its matching book folder. The translation folder may be named differently, but it must be directly inside /bible.

Use the reader

Build firmware with the Bible reader selected. On the Cardputer, choose Bible from Home, choose NLT Bible, then choose a book and chapter. The reader saves the listening position. Its keyboard controls are available with Alt+H; see the on-card Bible.txt help file for a short reference.
